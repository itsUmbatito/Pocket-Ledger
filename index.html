Smart receipt reading (optional)

Without a key, receipts are read on your phone for free. That works best for the total and the store name. With a Claude API key, Claude reads each item and sorts it into categories. It costs about 1 cent per receipt, paid to Anthropic. Get a key at console.anthropic.com.

Backup

Everything lives only on this phone. Save a backup now and then (to Files or iCloud Drive) so you can restore it. Backups never include your API key.
