# Pocket Ledger

A personal expense tracker with a budget plan built from your pay and goals, and receipt scanning. It runs as a home-screen web app on iPhone.

**Open it:** https://itsumbatito.github.io/Pocket-Ledger/

To install on iPhone: open the link in Safari, tap Share, then **Add to Home Screen**.

Your data is stored only on your phone. Use **Settings → Save backup** now and then.

Receipt scanning reads photos on the phone with [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0, files in `ocr/`). For item-by-item reading, add a Claude API key in Settings.
